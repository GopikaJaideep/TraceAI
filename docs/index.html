    Safeguards

    Designed against misuse

    Each control has an automated test.

    Stalking via a “missing” report

    Cases open only with a police reference and a family-violence check.

    Probing the tip form

    A tip returns a receipt, never a match.

    Fake or malicious tips

    Rate limits and flags. Tips only join a review queue.

    Insider snooping

    Per-case access and a tamper-evident audit log.

    Face-matching abuse

    Off unless the photo is attested as lawfully obtained.

    Keeping data forever

    Closing a case deletes its photo, face data and leads.

    Not a substitute for legal review, a privacy assessment, bias testing or a security audit.
